# Third-party components

The source repository contains application code and dependency manifests, without vendored Node modules or Qt / Chromium libraries. AppImage releases bundle the corresponding application, Qt / WebEngine, Node.js 22 and production controller dependencies. Lightweight tar releases use system Qt and separately installed controller dependencies. No distribution includes controller Fabric data or account credentials. Third-party terms remain applicable; a project source license has not yet been selected.

`controller/package-lock.json` pins the complete npm dependency graph and integrity hashes. It is not a complete license inventory: some packages omit a `license` field in their package metadata. Consult installed package `LICENSE`, `COPYING` and `NOTICE` files when distributing dependencies. Transitive components keep their respective licenses; listing a direct dependency above does not relicense its dependencies or this project.

Each AppImage contains `usr/share/doc/licenses/inventory.json` plus collected notices under `system/`, `node/`, `npm/` and `fonts/`. This records actual deployed package versions, npm metadata and missing-license-file markers. System package copyright files, Node's official license and installed npm `LICENSE` / `COPYING` / `NOTICE` files are retained. Inspect with `APPLICATION.AppImage --appimage-extract`. The inventory describes the bundle and does not grant a license for the application source.

The application icon is a small SVG included in `packaging/`. Application resources do not contain Apple artwork, Apple Home assets or recorded camera footage. Apple, HomeKit, Homebridge, Matter and Xiaomi / Mijia names identify interoperability targets and do not imply endorsement or certification.
